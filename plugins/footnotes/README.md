# Footnotes

Footnotes adds Markdown footnote references and definitions to Lore pages.

## Usage

```markdown
Lore keeps useful context.[^1]

[^1]: A compact footnote.
```

Footnotes are disabled by default. Enable this plugin when the wiki should recognize footnote syntax.

## Permissions

This plugin requests no Lore capabilities. It selects Lore's public `footnote` Markdown grammar.
