# Content

Lore pages combine a stable database identity with a human-readable path, title, Markdown body, and optional metadata. Paths form the navigation hierarchy and can be moved while aliases preserve historical paths.

Authoring features include live preview, formatting tools, wiki links, page templates, tags, groups, lifecycle metadata, properties, images, attachments, private drafts, and immutable revision history.
